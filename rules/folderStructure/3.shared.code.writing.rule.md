# Shared Code Writing Rules & Centralized Utilities Standards

(Universal Language-Agnostic Operational Rule for Polyglot Sub-Packages in Go, Python, Rust, Dart, Java, C#, C++, Node.js/TypeScript)

---

## 1. Strict Guardrails

Guardrail 1: Pure Shared Libraries (Zero Business Logic & Zero IO)
`src/shared/` must contain zero business domain logic, zero database queries, and zero network/disk IO. Shared utilities must be pure deterministic functions that take inputs and return outputs.

Guardrail 2: Centralized Observability & Tracing Invariant
Never instantiate ad-hoc OpenTelemetry tracer providers or raw logging clients inside feature services or handlers. Always import the centralized tracer and span decorators from `src/infra/observability/`.

Guardrail 3: Zero Magic Strings (Universal Constants Invariant)
Raw string literals for HTTP header keys, event topic names, database status enums, cache key prefixes, and canonical error codes are strictly prohibited. All string constants must be declared and imported from `src/shared/constants/`.

Guardrail 4: Centralized Date/Time & Currency Utilities Invariant
Never hand-roll date formatting, timestamp parsing, or currency calculations. Always import standardized UTC ISO 8601 formatters and integer/decimal money utilities from `src/shared/utils/`.

Guardrail 5: Middleware-First Boilerplate Elimination
Cross-cutting concerns (W3C trace extraction, request ID generation, auth token validation, tenant resolution, idempotency locks, rate limiting, and global exception mapping) MUST be implemented in centralized middleware pipelines, keeping delivery handlers thin and declarative.

Guardrail 6: Standard Error Hierarchy & Envelope Invariant
All application exceptions MUST inherit from the base `ApplicationError` in `src/shared/errors/`. Handlers and middleware must never emit raw uncaught exceptions or un-enveloped error payloads.

Guardrail 7: Zero Cross-Package Runtime Coupling
`src/shared/` and `src/infra/` must never import source code from `src/features/` or `src/api/`. Dependencies must flow strictly inward toward shared core modules.

Guardrail 8: Zero Inline Comments Doctrine
Never write mid-function inline comments inside shared utilities, middleware, or infrastructure adapters. Document the entire algorithmic execution workflow once in the file header docblock.

## 2. Shared Directory Inventory & Module Roles

All shared code is organized into 4 standardized submodules under `src/shared/`:

```yaml
shared_modules:
  constants:
    path: "src/shared/constants/"
    responsibilities:
      - "HTTP header names (TRACEPARENT, X_REQUEST_ID, X_CORRELATION_ID, IF_MATCH, etc.)"
      - "Standard canonical error codes (VALIDATION_FAILED, CONFLICT, RESOURCE_NOT_FOUND, etc.)"
      - "Common lifecycle status enums (PENDING, ACTIVE, SUSPENDED, ARCHIVED)"
      - "Default timeout budgets, pagination clamps, and rate-limit quotas"
  utils:
    path: "src/shared/utils/"
    responsibilities:
      - "Date & time: ISO 8601 UTC serialization, duration parsers, monotonic clock diffs"
      - "Crypto & hashing: SHA-256 canonical body hashing, UUIDv7 generation, token masking"
      - "Data transformation: List filtering, sorting, pagination slices, JSON sanitizers"
      - "Money & precision: Safe decimal arithmetic, currency formatting (never float)"
  errors:
    path: "src/shared/errors/"
    responsibilities:
      - "Base ApplicationError class with statusCode, canonicalCode, retryable, details"
      - "Derived typed errors: ValidationError, UnauthorizedError, ForbiddenError, NotFoundError, ConflictError, PreconditionFailedError, TimeoutError"
  types:
    path: "src/shared/types/"
    responsibilities:
      - "Standard ApiResponse and ApiErrorResponse generic envelope types"
      - "Pagination request and metadata response interfaces"
      - "Common sorting, filtering, and W3C trace context data models"
```

## 3. Boundary Invariants: `src/shared/` vs `src/infra/`

Per `0-package-folder-writing-rule.md`, enforce strict architectural boundary isolation between shared utilities and infrastructure engines:

1. **`src/shared/` Boundary (Zero IO & Pure Logic)**:
   - Contains ONLY pure utilities (`utils/`), system constants (`constants/`), application error definitions (`errors/`), and generic envelope types (`types/`).
   - MUST NEVER import database connection pools, Kafka clients, Redis connections, HTTP drivers, or environment variables.
2. **`src/infra/` Boundary (Centralized Runtime Engines)**:
   - All connection pools, database driver adapters, Kafka producers/consumers, tracing SDK initialization, and configuration loaders live exclusively in `src/infra/`.
   - Feature domain services and shared utilities must NEVER open raw network connections or instantiate ad-hoc SDK clients.

## 4. Middleware-First Boilerplate Elimination

Handlers MUST delegate cross-cutting concerns to centralized HTTP middleware:

1. **Trace & Request Context Middleware**:
   - Extracts W3C `traceparent` or creates synthetic root span.
   - Extracts `x-request-id`, `x-correlation-id`, `x-tenant-id`, `x-client-id` into thread-local / async request context.
   - Injects trace and request headers into outgoing response.
2. **Authentication & Tenant Isolation Middleware**:
   - Validates Bearer JWT / mTLS certificate against auth provider.
   - Sets authenticated `user_id`, `tenant_id`, and roles on the request context.
3. **Idempotency & Concurrency Middleware**:
   - Hashes canonical request body (`SHA-256`) and checks `(x-idempotency-key, hash)` in idempotency store.
   - Acquires distributed lock before handler execution; releases on completion.
4. **Global Exception-to-Envelope Middleware**:
   - Catches all `ApplicationError` exceptions and maps them directly into the standard Error Response Envelope.
   - Catches unhandled panics/exceptions, logs them with trace context, and emits `500 INTERNAL_SERVER_ERROR`.

## 5. AI Agent Implementation Instructions

### Instruction 1: Check Shared Constants & Utilities First
Before creating any string literal, date parser, or hash utility, inspect `src/shared/constants/` and `src/shared/utils/`. NEVER invent duplicate string keys or local date-formatting functions inside feature modules.

### Instruction 2: Use Shared Error Classes
Throw typed domain errors inheriting from `src/shared/errors/` instead of generic language exceptions:
- Use `ValidationError` for schema and input bounds failures (HTTP 400).
- Use `NotFoundError` when unique identifiers do not exist (HTTP 404).
- Use `ConflictError` on unique constraint or state collisions (HTTP 409).
- Use `PreconditionFailedError` on `If-Match` ETag mismatches (HTTP 412).

### Instruction 3: Apply Centralized Tracing Decorators
Wrap domain service methods and external client calls using the shared span decorator:
```python
@with_span("domain.feature.operation")
async def execute_operation(self, input_dto: FeatureInputDTO) -> FeatureOutputDTO:
    ...
```

### Instruction 4: Rely on Middleware for Ingress Concerns
Keep API handlers under 30 lines by letting middleware handle authentication, tracing, validation parsing, and error-to-envelope mapping.
